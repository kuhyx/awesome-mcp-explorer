Filter and sort every server in punkpeye/awesome-mcp-servers by Glama grade, licence, scope, language, OS, popularity and activity.

This page is the explorer itself: with JavaScript on, it loads every server from awesome-mcp-servers — about 3,000 of them — into one filterable, sortable list. Every filter lives in the URL, so a view can be bookmarked or shared.

Example

Every triple-A, FOSS, local-only Rust server, most recently pushed first:

?aaa=1&foss=yes&scope=local,!cloud&lang=rust&sort=pushed
